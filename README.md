# Transformer Implementation From Scratch

A complete implementation of the Transformer architecture in PyTorch, built from first principles while studying the paper *Attention Is All You Need*.

## Goals

- Implement every Transformer component from scratch
- Understand the mathematics behind every tensor operation
- Learn PyTorch engineering practices
- Build an educational reference implementation
